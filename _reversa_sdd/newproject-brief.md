## Ideia original
Sistema Multiagentes de Análise Financeira desenvolvido em Python (utilizando CrewAI ou LangGraph e APIs de LLM).

O sistema orquestra 3 agentes especializados para resolver um problema de negócio real:
1. **Agente de Coleta de Dados (Scraper/Market Data):** Realiza a varredura e extração de dados financeiros/mercado via web scraping ou APIs de dados de mercado.
2. **Agente Analista / Matemático:** Recebe os dados e aplica modelos estatísticos, indicadores quantitativos ou fórmulas de otimização.
3. **Agente Relator / Sintetizador:** Gera um relatório consolidado e estruturado com insights e conclusões estratégicas.

### Requisitos Chave e Diferenciais:
- Arquitetura sólida de comunicação inter-agentes.
- Tratamento explícito de loops de decisão e controle de fluxo.
- Mecanismos de mitigação de alucinação (validação de dados e saídas estruturadas).
- Documentação técnica e README detalhado explicando o design da solução.
