Visão Geral do Módulo `utils` 🟢 CONFIRMADO

O módulo utils fornece suporte de infraestrutura transversal:

  • setup_logging: Configuração centralizada de logs formatados.
  • handle_max_iter_reached: Emissão de alerta de salvaguarda quando o limite de iterações do grafo é excedido.
