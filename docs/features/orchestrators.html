Visão Geral do Módulo `orchestrators` 🟢 CONFIRMADO

O módulo orchestrators implementa o paradigma de dupla orquestração:

  • LangGraphOrchestrator: Máquina de estados baseada em StateGraph com controle rigoroso de iterações (`max_iter = 3`) e gatilho de salvaguarda `MAX_ITER_REACHED`.
  • CrewAIOrchestrator: Encadeamento sequencial simples estilo Task Chaining.
